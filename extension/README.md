# Hanzi Burst — Chrome extension

Select Chinese text on any page → card with pinyin, meaning and the character's components. Fully offline.

Build (needs `site/data/`, which is generated by the site build):

    python3 scripts/build_extension.py --zip

Then load `extension/` via chrome://extensions → Developer mode → Load unpacked.
`extension/data/` and `extension/icons/` are generated and git-ignored.

The zip is also built by every site deploy (`wrangler.toml` [build]) and served at
https://hanzi.lipu.dev/hanzi-burst-extension.zip. To release a new version to the Chrome Web Store,
bump `version` in `manifest.json`, merge to `main`, then push tag `v<version>`: see the root README, section «Деплой».
