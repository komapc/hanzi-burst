# Roadmap / идеи

Теоретические задачи: описаны, но не начаты. Порядок не жёсткий.

## «Анализ» своего текста: вставить или сфотографировать

**Идея.** Пользователь вставляет китайский текст (или фотографирует вывеску, страницу учебника, меню), нажимает «Анализировать» и получает ту же интерактивную фразу: сегментация на слова, пиньинь, перевод, клик по иероглифу → разбор на радикалы. Сейчас сайт работает только с заранее собранными фразами (пул ~2200).

### Вариант A: вставка текста — СДЕЛАНО (v1)
Реализовано клиентом: `scripts/build_shards.py` → `site/data/{chars,glyphs,words}/<hh>.json` (+`trad.json`), сегментация максимальным совпадением в `index.html`, deep link `?t=`. Перевод всей фразы — кнопка «Перевести» (`/api/translate`, Gemini, лимит на IP в сутки); ей же пользуется расширение. Ниже исходные соображения.
- Сегментация и словарь должны быть доступны в рантайме. Сейчас `phrase.json` содержит только слова из заготовленных фраз.
- Клиентский вариант: словарь CC-CEDICT, разбитый на шарды по блокам кодпоинтов или по первому иероглифу (подгружать лениво), сегментация в JS (максимальное совпадение / DP по частотам). Плюс: без сервера, без лимитов. Минус: размер словаря (~10 МБ несжатым, ~3 МБ gzip), нужен перевод определений на русский на лету (пока переводы только для иероглифов из данных).
- Серверный вариант: Worker + D1 с таблицей слов. Плюс: лёгкий клиент. Минус: нагрузка и лимиты.
- Разбор иероглифов уже есть для 629 знаков; для остальных нужны данные Make Me a Hanzi целиком (≈9 тыс. знаков) в виде шардов (`glyphs`, `chars`) или запросов к D1.
- Перевод всей фразы: Gemini (с лимитами, как у запоминалок) или показывать только пословный перевод из словаря.

### Вариант B: фото
- Распознавание: Gemini vision (один запрос = распознанный текст + перевод) либо Tesseract.js с `chi_sim` на клиенте (бесплатно, медленнее, хуже на фото).
- Дальше как в варианте A.
- Приватность: фото уходит в Google; нужен явный текст в интерфейсе и обновление `/privacy`. Лимиты на пользователя/IP обязательны.

### Открытые вопросы
- Нужен ли вход (лимиты на пользователя, история текстов)?
- Хранить ли введённые тексты (по умолчанию нет: только в браузере).
- Традиционные иероглифы: конвертировать в упрощённые перед разбором?
- Атрибуция и лицензии при расширении данных (CC-CEDICT CC BY-SA, MMH LGPL).
